
AI 감정일기 앱을 만들거야

1. "오늘의 하루는 어땠나요?" 라는 제목을 보여줘
2. 사용자가 여러 줄의 텍스를 입려할 수 있는 넓은 입력창(TEXTAREA)을 만들어줘
3. 입력창 아래에 "음성으로 입력하기" 버튼과 "분석 요청하기" 버튼을 만들어줘
4. 가장 아래에는 "AI 답변" 이라는 소제목과 함께, 
   AI 의 답변이 표시될 회색 배경의 박스를 만들어줘.
   처음에는 "여기에 AI 답변이 표시됩니다." 라고 쓰여있게 해줘




이제 음성 인식 기능을 추가하자.

사용자가 "음성으로 입력하기" 버튼을 클릭하면, 브라우저의 내장 음성 인식 기능을 활성화 해줘
(Web Speech API 를 사용해줘)
사용자가 말을 하면, 그것을 텍스트로 변환해서 넓은 입력창에 자동으로 채워 넣어줘.
음성 인식이 시작되면 버튼의 텍스트를 "음성 인식 중..."으로 바꿔주고,
인식이 끝나면 다시 "음성으로 입력하기" 로 돌려줘 
음성이 인식 되는 동안에는 "음성 인식 중..." 의 글자가 깜빡 거리게 해줘.
5초 이상 음성 입력이 없으면 음성 인식 종료 해줘
인식 종료 전까지 계속 이어서 입력이 되게 해줘







이제 google gemini API 를 사용할 거야

내가 발급 받은 API 키를 안전하게 설정하고 싶어.
환경 변수를 사용해서 "GEMINI_API_KEY' 라는 이름으로 이 키를 저장하고, 
코드에서 불러와서 사용할 수 있게 해줘.






"분석 요청하기" 버튼을 클릭했을 때의 동작을 만들자.
1. 사용자가 입력창에 작성한 일기 내용을 가져와
2. 설정한 Gemini API 키를 사용해서, Gemini API 를 호출해줘.
3. API 를 호출할 때 다음과 같은 프롬프트 를 전달해야해
   "너는 심리 상담가야. 사용자가 작성한 일기 내용을 읽고, 사용자의 감정을 한 단어 
   (예:기쁨, 슬픔, 분노, 불안, 평온)로 요약해줘. 그리고 그 감정에 공감해주고, 따뜻한 응원의 메시지를
   2~3문장으로 작성해줘. 답변 형식은 반드시 '감정:[요약된 감정]\r\n[응원 메시지]' 와 같이
   줄 바꿈을 포함해서 보내줘"
4. API 로부터 받은 답변을 화면 아래쪽의 회색 박스에 표해해줘.
5. .env 의 GEMINI_API_KEY 환경변수를 입력했어.
   해당 환경변수를 로직에 적용해줘. 최산 flash 모델을 사용할꺼야.
   




이제 일기 내용과 AI 답변을 브라우저의 로컬 스토리지에 저장해서, 새로고침해도 내용이 유지되게 해줘

1. 사용자가 '분석 욫ㅇ하기'를 눌러 AI 의 답변을 받으면, 
   그 시점의 일기 내용과 AI 답변을 로컬 스토리지에 저장해줘.
2. 페이지가 처음 로드 될 때, 로컬 스토리지에 저장 된 내용이 있는지 확인하고, 
   만약 있다면 그 내용을 입력창과 AI 답변 박스에 각각 채워 넣어줘.
