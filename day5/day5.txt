
AI 감정일기 앱을 만들거야

1. "오늘의 하루는 어땠나요?" 라는 제목을 보여줘
2. 사용자가 여러 줄의 텍스를 입려할 수 있는 넓은 입력창(TEXTAREA)을 만들어줘
3. 입력창 아래에 "음성으로 입력하기" 버튼과 "분석 요청하기" 버튼을 만들어줘
4. 가장 아래에는 "AI 답변" 이라는 소제목과 함께, 
   AI 의 답변이 표시될 회색 배경의 박스를 만들어줘.
   처음에는 "여기에 AI 답변이 표시됩니다." 라고 쓰여있게 해줘




이제 음성 인식 기능을 추가하자.

사용자가 "음성으로 입력하기" 버튼을 클릭하면, 브라우저의 내장 음성 인식 기능을 활성화 해줘
(Web Speech API 를 사용해줘)
사용자가 말을 하면, 그것을 텍스트로 변환해서 넓은 입력창에 자동으로 채워 넣어줘.
음성 인식이 시작되면 버튼의 텍스트를 "음성 인식 중..."으로 바꿔주고,
인식이 끝나면 다시 "음성으로 입력하기" 로 돌려줘 
음성이 인식 되는 동안에는 "음성 인식 중..." 의 글자가 깜빡 거리게 해줘.
5초 이상 음성 입력이 없으면 음성 인식 종료 해줘
인식 종료 전까지 계속 이어서 입력이 되게 해줘
